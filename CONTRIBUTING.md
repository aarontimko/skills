# Contributing

This repository is one person's working set of agent skills, published in the open. It is
not a community project, so pull requests are not accepted and will be closed with a
thank-you.

What is welcome:

- **Forks.** Take any skill, change it, publish your version. Apache-2.0 allows it; keep
  the NOTICE file with what you redistribute.
- **Bug reports** about `scripts/`, the git hooks, or the plugin manifests, through the
  issue form.
- **Feedback** on a skill: where it misfired, what it made an agent do that you did not
  want, a better approach you have seen work. Open a blank issue.

Security problems never go in an issue; see [SECURITY.md](SECURITY.md).

If you fork and edit your copy in place, `AGENTS.md` describes the layout and the checks
your commits will go through.
